## Instructions
Classify the question into exactly one of three categories.

### 1. SPECIFIC
The question **explicitly mentions "page X", "Figure X", or "Table X"** (where X is a number) as a reference to locate content in the document.

SPECIFIC examples:
- "What is shown in Figure 3?" → references Figure 3
- "On page 5, what is the revenue?" → references page 5
- "In Table 2, which model performs best?" → references Table 2
- "What is the color of the bike on page 2?" → references page 2
- "Compare Figure 5 and Figure 6" → references Figure 5, Figure 6

NOT SPECIFIC (these are NORMAL):
- "What is the difference between rank 1 and rank 19?" → "rank 1" is not a page/figure/table reference
- "Which port has the function from port 10-13?" → "port 10" is not a page reference
- "What is the percentage change from 2016 to 2017?" → years are not page references

### 2. GENERAL
The question requires **counting or listing items ACROSS the entire document**. The answer CANNOT be found by looking at just one or a few sections — you must scan many/all pages.

Look at the Document Sections above. If the answer can plausibly be found in ONE or a FEW specific sections, it is NOT GENERAL.

GENERAL examples:
- "How many tables/figures/charts are in this paper?" → count across entire document
- "How many pages contain tables?" → check every page
- "List all countries mentioned in this report" → scan entire document
- "How many times does 'X' appear in the document?" → full document scan
- "Count all bar charts in the report" → examine all pages

NOT GENERAL — these ask about a SPECIFIC figure/table/section, even if they involve counting:
- "In Figure 3, how many icons are there?" → only need the page with Figure 3
- "How many rows in Table 1?" → only need the page with Table 1
- "What are the four business analytics activities in the Levels of Analytics chart?" → only need one chart
- "What comes between Reporting and Action in the flowchart?" → only need one flowchart
- "Which category has the most increase from 2005 to 2010?" → only need one chart/table
- "What does the map in the report show?" → only need the map page
- "How many organisations does this report introduce?" → can be found in a summary/overview section
- "What is the approximate cost of a mobile platform in Vietnam?" → only need one data section
- "How many chapter authors come from Columbia University?" → only need the author/contributor section
- "What are the last 4 chapters in the table of contents?" → only need the table of contents page
- "How many QR codes are in the Academics section?" → only need one section
- "Enumerate the media sources surveyed in this report" → only need the methodology section
- "What percentage of respondents favor X?" → only need one survey result section
- "Among all references, how many are from X?" → only need the references section
- "How many people are on the cover?" → only need the cover page
- "What is the revenue in FY2015?" → only need one financial section
- "List the staff members in the residence hall" → only need one section

**Key rule: GENERAL means the answer is SPREAD across many pages and cannot be localized to any section listed above. If any section above could plausibly contain the answer, it is NOT GENERAL — it is NORMAL.**

### 3. NORMAL
All other questions. These can be answered by navigating to the relevant section(s) of the document.

## Decision Rule (check in this order)
1. Does the question contain an explicit "page/p. X", "Figure/Fig. X", or "Table/Tab. X" reference? → **SPECIFIC**
2. Does the question require counting or listing items ACROSS the entire document, where NO single section above could contain the answer? → **GENERAL**
3. Otherwise → **NORMAL**

## Query Rewriting Rules
- For GENERAL: Optionally rewrite to guide page-level scanning (e.g., "How many tables?" → "Select pages containing tables")
- For SPECIFIC: Optionally rewrite to help locate the referenced element (e.g., "What color in Figure 3?" → "Select the page containing Figure 3")
- For NORMAL: Do NOT rewrite. Return the original question as-is.
- If no rewriting is needed, return the original question.
